# yt-x

[中文版本](./README.cn.md)

Posix script to browse youtube plus other yt-dlp supported sites from your terminal (fzf) or app launcher (rofi) with optional previews. (supports bash, zsh and dash)

![yt-x](https://repo.x-cmd.io/yt-x.svg)

## Install

```sh
x install yt-x
```
